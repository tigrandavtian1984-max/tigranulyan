# tigranulyan

Сайт-портфолио фотографа Тиграна. Статический сайт: `index.html` и папка `photos/`.

Новые работы добавляются строкой в массив `PHOTOS` в `index.html` (файл, тип съёмки, ширина и высота).

Для страницы «Все работы» у каждого фото есть маленькая квадратная копия 200×200 в `photos/p/` с тем же именем (это планеты на фоне). Если копии нет, берётся `photos/t/`.
